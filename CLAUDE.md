# Claude Code instructions: isolated Universal Modder lab

This repository is a self-contained test only. Do not inspect, read, copy, modify, or run programs in any neighboring directory or repository. In particular, do not access the Clone Wars Command or attack-cruiser codebase.

## Allowed work

* Inspect files under this repository.
* Add ORIGINAL test assets, project-scoped scripts, tests and documentation.
* Use the existing Node.js local viewer.
* Create short, reproducible generation reports.

## Hard boundaries

1. Do not change the current user's other repositories, game installs, global Git settings, environment configuration, Windows registry, or running applications.
2. Never install a plugin or tool, grant permissions, register an MCP server, open an external account, or make a paid API request without asking first.
3. Price each external generative model before requesting assets. Tell the owner what will be sent to the service and what it is estimated to cost. Wait for explicit approval.
4. Never disclose or commit API keys, tokens, private game data, copyrighted game assets, or user files.
5. Do not push, publish, open pull requests, or change GitHub repository visibility without direct approval.
6. Prefer simple changes. Preserve working controls and baseline viewer scenes. Do not rewrite unrelated code.
7. Validate generated assets before treating them as game ready. Check render quality, geometry count, file size, texture resolution and licensing conditions.
8. If dependency installation is needed, propose local project-scoped methods first.
9. Never use extracted assets from any Star Wars or other commercial game. Original, generic science-fiction examples only.

## Report after each experiment

Document the exact inputs, tool names/versions, model name, estimated and actual generation costs where available, asset provenance, created files, tests run, performance observations, problems, and commit hash (only when a commit is approved and made).

Read docs/EXPERIMENT_01.md before starting the first generation experiment.
