# Codex instructions for UniversalModder lab

This PUBLIC repository is an independent experiment. Its purpose is to evaluate generative 3D assets using Universal Modder. It is NOT Clone Wars Command.

## Hard limits

1. Work only in this repository. Never inspect, modify, copy, or search the Clone Wars Command or attack-cruiser repository, neighboring folders, or other game installs.
2. Read docs/EXPERIMENT_02_VENATOR_CODEX.md for the Venator experiment. The older docs/EXPERIMENT_01.md is for an unrelated command-console experiment.
3. Do not install plugins, system utilities or packages, configure MCP, change environment variables, run generated external scripts, or change machine settings without user approval.
4. Do not run any billable API generation until the user reviews the real price and authorizes a precise spending cap. Request separate approval before converting the concept image to 3D. One asset per approved step, no automatic retries or batches.
5. API keys must not appear in chat messages, committed files, scripts, logs, screenshots or public issues. Use the toolkit's local secure key prompt where possible.
6. Any Venator imagery or models are private experimental fan art. Keep all outputs local and inside gitignored generated/venator01. Do not commit, push or publish copyrighted reference assets, derivatives, generated outputs, or private files.
7. Do not use any files, models, textures or audio from another commercial game. Only make new concept art from a textual prompt.
8. Prefer read-only inspection and local isolated tests. Preserve any working viewer source unchanged unless the task requires a narrow fix with a regression test.
9. Never commit or push without explicit approval.
10. Report exact commands performed, actual resulting file paths, generator names, current pricing, actual spend if known, quality problems, render checks, and tests. Distinguish verified evidence from assumptions.
